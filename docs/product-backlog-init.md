# Product Backlog inicial — TaskFlow Lite

| Capacidad | Clasificación | Valor |
|---|---|---|
| Registrar una nueva tarea | Esencial para MVP | Permite incorporar el trabajo que el equipo necesita realizar y dar seguimiento. |
| Visualizar las tareas registradas | Esencial para MVP | Proporciona visibilidad inmediata sobre el trabajo existente del equipo. |
| Identificar el estado de cada tarea | Esencial para MVP | Permite distinguir claramente qué tareas están pendientes, en curso o terminadas. |
| Actualizar el estado de una tarea | Esencial para MVP | Permite reflejar el avance real del trabajo conforme una tarea progresa. |
| Conservar las tareas y sus cambios entre sesiones | Esencial para MVP | Evita perder la información y permite continuar el seguimiento posteriormente. |
| Editar la información de una tarea existente | Posterior | Permite corregir o ajustar los datos de una tarea después de haberla registrado. |
| Eliminar tareas | Posterior | Permite retirar tareas que ya no sean necesarias o hayan sido registradas incorrectamente. |
| Filtrar tareas por estado | Posterior | Facilita localizar trabajo específico cuando aumente la cantidad de tareas registradas. |
